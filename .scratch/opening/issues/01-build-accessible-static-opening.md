# 01: Build the accessible static Opening

**Specification:** [Opening: Accessible Static Introduction](../spec.md)

**What to build:** A locally runnable, responsive, static introduction that lets
a recruiter identify Ivan Siachoque's professional positioning and reach his
email or LinkedIn profile. Establish the original nighttime city identity using
the agreed React, Vite, TypeScript, GSAP, and vanilla-extract stack.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The application runs locally, passes TypeScript checking, and builds for production.
- [ ] The Opening displays the exact approved name, professional headline, introduction, and supporting copy in English.
- [ ] Get in touch and LinkedIn are real links with the approved destinations.
- [ ] Original, project-local nighttime artwork establishes the visual identity; any conceptual portrait is identified as illustrative.
- [ ] The composition remains readable and usable on desktop, at 320 CSS pixels, and on a short landscape viewport without horizontal overflow.
- [ ] Keyboard navigation, visible focus, semantic structure, text contrast, and contact targets meet the specification.
- [ ] Text reflow, image-failure fallback, and reduced-motion behavior are verified in the browser.
- [ ] No animation, unfinished navigation, additional chapters, CV download, or external deployment is introduced.
- [ ] Browser findings and verification limits are recorded.
- [ ] Standards and specification reviews are completed against a recorded Git baseline, and actionable findings are resolved.
